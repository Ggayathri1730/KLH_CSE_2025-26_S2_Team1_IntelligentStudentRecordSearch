## Intelligent Student Record Search System

The Intelligent Student Record Search System is a search application designed to quickly find student information from a large collection of records.

Instead of relying only on simple searching, the system uses different **string-matching and text-processing algorithms** to improve search speed and accuracy. It implements Naïve Pattern Matching, Knuth-Morris-Pratt (KMP), Rabin-Karp, and Edit Distance algorithms.

Users can search for student details such as names, IDs, or other text fields. The system can also handle **partial matches and spelling mistakes**, making it more flexible than a basic search system.

### Key Features

* Fast searching through student records
* Multiple string-matching algorithms
* Typo-tolerant search using Edit Distance
* Comparison of different searching techniques
* Demonstrates practical use of **Data Structures and Algorithms**
* Designed to work efficiently with large student datasets

This project demonstrates how advanced string-matching algorithms can be applied to a real-world student record management and search problem.
